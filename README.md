# محاسبه‌گر فرمول گمرکی — پاوه ۱۴۰۵

اپلیکیشن تک‌صفحه‌ای Next.js (App Router + TypeScript + Tailwind CSS) که فرمول‌های شیت «Sheet1» فایل اکسل
`فرول گمرکی1405 پاوه-1.xlsx` را با طرح «داشبورد» پیاده‌سازی می‌کند.

## اجرا

```bash
pnpm install
pnpm dev
```

آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:3000`) را باز کنید.

## ساخت نسخه نهایی

```bash
pnpm build
pnpm start
```

## ساختار

- `src/lib/calc.ts` — تمام فرمول‌های اکسل، سلول به سلول، با کامنت شماره سلول اصلی (مثلاً `G2`, `E18`). با فایل اکسل مرجع تطبیق داده و تأیید شده است.
- `src/lib/useSettings.ts` — هوک نگهداری تنظیمات پیشرفته در `localStorage` مرورگر (بدون هیدریشن‌میسمچ، با `useSyncExternalStore`).
- `src/components/Calculator.tsx` — کامپوننت اصلی که فرم، بنر KPI، شبکه نتایج و پنل تنظیمات را به هم متصل می‌کند.
- `src/components/{Header,KpiBanner,FormCard,StatGrid,SettingsModal,NumberField}.tsx` — اجزای رابط کاربری.
- فونت Vazirmatn به‌صورت self-host از `public/fonts/` بارگذاری می‌شود (بدون وابستگی شبکه‌ای به Google Fonts در زمان build یا اجرا).

## نگاشت فیلدها

**فرم اصلی (هر بار پر می‌شود):**
تعداد (A2)، ارزش کالا (D2)، دلار گمرکی (E2 — پیش‌فرض دارد، قابل تغییر)، بیمه و کرایه (F2 — پیش‌فرض دارد، قابل تغییر)، ضریب حقوق گمرکی (C3)، ضریب سود بازرگانی (C4)، آزمایشگاه (E15)، هزینه متفرقه (E20).

**تنظیمات پیشرفته (ذخیره در localStorage):**
B3, B4, D5, D6, D8, D9, D10, D16, E13, E14, E17.

**Sheet2** و جدول تبدیل ارز شیت اول در این نسخه پیاده‌سازی نشده‌اند (طبق تصمیم قبلی، چون هیچ فرمولی آن‌ها را به محاسبه‌گر متصل نمی‌کرد).

## طرح

طرح «داشبورد» (طرح ۲ از بوم طراحی اولیه) پیاده‌سازی شده است: بنر KPI بالای صفحه با مجموع کل و ارقام کلیدی در یک نگاه، و اجزای هزینه به‌صورت شبکه کارت قابل‌مرور.
